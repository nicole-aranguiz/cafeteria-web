Lali la cafetería
Descripción del proyecto
"Lali la cafetería" es un sitio web diseñado para una cafetería local en Viña del Mar. 
El proyecto busca presentar una propuesta visualmente atractiva y funcional donde se muestre el menú, la identidad de la marca
y la información de contacto para sus clientes, optimizando la experiencia de navegación con un diseño moderno y elegante.

Problemática abordada
El desafío principal era crear una plataforma digital que transmitiera la esencia acogedora y profesional de la cafetería, 
garantizando al mismo tiempo que la información fuera accesible y fácil de encontrar. 
Además, se abordó la necesidad de contar con una estructura  que permitiera a los usuarios navegar cómodamente tanto desde 
computadores como desde dispositivos móviles, cumpliendo con los estándares de accesibilidad web actuales.

Tecnologías utilizadas
Para el desarrollo de este proyecto se utilizaron las siguientes tecnologías:

HTML: Estructura semántica del contenido.

CSS3: Estilos, paleta de colores personalizada y efectos de animación.

Bootstrap 5: Framework CSS para el diseño responsivo.

Git/GitHub: Control de versiones para el seguimiento y despliegue del proyecto.

Uso de Inteligencia Artificial
En el desarrollo de este proyecto, se utilizó la Inteligencia Artificial como un "copiloto" de programación. La IA fue empleada 
para:

Consultoría de diseño: Selección y armonización de una paleta de colores coherente y profesional, ya que queria utilizar colores
nude, pasteles, como rosa palo, cafey también para la implementación de botones para que asi quedara mas centrado y se viera 
bien esteticamente.
